# 友情链接申请

欢迎与内容健康、持续维护的网站交换友情链接。

### 申请格式

```yaml
name: 站点名称
desc: 站点简介
url: https://example.com/
avatar: https://example.com/avatar.png
```

### 申请须知

- 请先在你的网站添加本站链接。
- 站点内容需合法、可访问，并且长期维护。
- 申请信息审核通过后会手动添加。
