# 隐私政策

**更新日期：2026 年 10 月 24 日**  
**生效日期：2026 年 10 月 24 日**

欢迎来到 [泠の小站](https://sgexilq.com/)（以下简称“本站”）。本站重视您的隐私和个人信息保护。本页面说明您访问本站时，本站如何处理访问、评论、搜索及其他功能产生的信息。

## 自建服务

本站的评论、音乐解析、GitHub 热榜解析、文章点赞、状态查询等接口均由本站自行开发，并主要部署于 Vercel；本站域名、静态资源及普通页面访问由 Cloudflare 提供代理、缓存或托管服务。

访问这些服务时，Cloudflare 和 Vercel 作为基础设施平台，可能按照其各自服务条款和隐私政策处理必要的请求日志、IP 地址、访问时间、User-Agent 等基础设施信息。GitHub 热榜解析服务会在服务器端获取 GitHub 的公开数据，访客不会因此直接向 GitHub 提交个人信息。

Cloudflare 同时为本站提供 CDN 加速、缓存、安全防护和恶意请求拦截。为完成缓存、限流及安全判断，Cloudflare 可能处理 IP 地址、User-Agent、TLS 指纹、请求路径、访问时间及访问结果等信息；可疑或恶意请求可能被挑战、限流或阻断。

文章点赞功能若启用了云端计数与限流，服务端可能会根据 IP 创建临时限流记录。该记录仅用于防止接口滥用，通常会在约两分钟内自动过期。

## 信息收集与使用

### 在您访问时

为了提供网页、接口、安全防护和基础统计，本站及其实际使用的 Cloudflare、Vercel 等基础设施平台可能接收以下信息：

- **网络信息**：IP 地址、浏览器 User-Agent、请求时间、请求页面等
- **设备与浏览器信息**：操作系统、浏览器类型、屏幕或视口尺寸等必要信息
- **访问行为**：页面访问、站内搜索、音乐播放、图片查看等由您主动触发的操作

本站不会要求您注册账号，也不会为了广告投放而建立访客画像。

### 第三方数据与资源服务

当前站点可能访问以下第三方服务：

- **不蒜子**：用于统计站点访问量和访客数量；当其服务异常时，会自动降级使用本站自建统计端点继续计数与展示（口径一致，数据仅供参考）。
- **天气服务**：
  - 默认使用高德开放平台，可能涉及 IP 定位或浏览器地理定位；
  - 可选天气数据源包括 wttr.in 和 Open-Meteo；
  - 使用浏览器地理定位且需要获取城市名称时，可能请求 OpenStreetMap Nominatim。
- **Algolia**：启用在线搜索时，搜索关键词及相关请求信息会发送至 Algolia；离线或请求失败时可能自动降级为本地搜索。
- **一言 Hitokoto**：用于加载首页一言内容。
- **jsDelivr**：用于加载 Twikoo 评论脚本。
- **SUSTech Open Source Mirrors**：用于加载 Fancybox 图片灯箱资源。
- **网易云音乐 CDN**：用于获取音乐播放所需的音频和相关媒体资源。

浏览器只有在相应功能实际启用或被触发时，才会产生上述第三方请求。

### 邮件中转

本站的联系邮箱及部分回复通知可能通过 Cloudflare Email Routing 等邮件中转服务处理。Cloudflare 会为完成邮件投递而处理发件人地址、收件人地址、邮件头及邮件内容；邮件最终还会由实际接收邮箱的服务商处理。

## 在您评论时

评论使用无需登录的匿名评论系统。您可以自愿填写昵称、邮箱、网址和评论内容。建议使用不易被恶意识别的昵称；邮箱不会显示在评论区，但可用于接收回复通知。

评论服务可能记录 IP 地址、User-Agent、访问时间和评论内容等信息，用于识别垃圾评论、滥用行为及排查故障。本站不会主动公开完整的 IP 地址。

评论头像可能根据您填写的邮箱向 Cravatar 或其他头像服务发起请求；使用 QQ 邮箱时，也可能请求 QQ 头像。相关信息由对应的第三方服务按照其自身规则处理。

## 本地存储

本站主要使用浏览器的 LocalStorage 保存必要的本机状态，包括：

- **个性化配置**：主题、字体、布局、播放器和小组件设置等
- **阅读数据**：阅读历史、进度和最近访问位置
- **加密文章状态**：已成功解锁的文章记录
- **点赞状态**：本机已经点赞或取消点赞的文章
- **评论用户信息**：评论系统使用的本机昵称等兼容数据

您可以随时通过浏览器设置清除这些数据。清除后不会删除站点内容，但可能重置个性化设置、阅读进度、已解锁文章状态和本机点赞状态。

本站自身不会主动设置广告追踪 Cookie。第三方服务可能依据各自的隐私政策使用 Cookie 或其他浏览器存储机制。

## 信息的分享和披露

本站不出售、交易或出租您的个人身份信息。为提供服务和防止滥用，必要信息可能由本站实际使用的基础设施或数据服务商在其服务范围内处理，例如 Cloudflare、Vercel 及其集成的存储、限流或搜索服务。

除法律要求、保护本站合法权益或紧急情况下保护人身安全外，本站不会向无关第三方披露您的信息。

## 第三方网站

本站可能包含指向其他网站的链接。本站不对第三方网站的隐私政策或内容负责。离开本站访问其他网站时，请阅读对应网站的隐私政策。

## 安全性

本站会采取合理的技术和管理措施，降低信息被未经授权访问、篡改或泄露的风险。但由于网络服务和第三方平台的固有限制，无法保证任何信息传输或存储绝对安全。

## 隐私政策的变更

本站可能适时更新本隐私政策。重要调整会在本页发布，并更新页面顶部的日期。
